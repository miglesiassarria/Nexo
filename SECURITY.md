# Seguridad

Nexo está pensado para ejecutarse en local. Hasta que existan controles de identidad, TLS y almacenamiento seguro de secretos, no debe exponerse a Internet ni a una red compartida.

No incluyas en issues, logs o pull requests:

- API keys.
- Access tokens o refresh tokens OAuth.
- Cookies de sesión.
- Contenido sensible enviado a los modelos.

Para reportar una vulnerabilidad, abre un aviso privado en GitHub si el repositorio lo permite. No publiques credenciales ni un exploit funcional en un issue público.
